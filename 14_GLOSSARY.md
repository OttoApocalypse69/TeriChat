# Glossary

## BLOAT

**Background Logistics, Optimization, Archival & Telemetry**

Legitimate background maintenance subsystem.

## BroadcastRoom

Generic synchronized audience/media room primitive that can back Cinema, lectures, presentations, all-hands, etc.

## Cinema

First-class watch-party channel specialization with synchronized media, quiet audience defaults, reactions, whispers, and higher-quality media profiles.

## Economy

Built-in virtual workspace economy based on a double-entry ledger. Completely separate from real-money billing.

## Entitlement

Effective capability/quota derived from plans, boosts, workspace subscriptions, and policy.

## Gateway Intent

Event category an application/bot is allowed to receive.

## Permission

Action a principal is allowed to perform.

## SPICE

Existing music project used as the preferred media/source backend for TeriChat's built-in Music service.

## Stats

Built-in activity/leaderboard/achievement service that consumes metadata events without needing plaintext message content.

## TeriChat

Temporary product/repository codename. Final platform name TBD.

## TeriCrypt-4096™

Security/cryptography suite branding. Uses established cryptographic implementations and does not imply custom 4096-bit homemade cryptography.

## Workspace

Independent user/community/team space. May be presented as a "Server" in social UX.


## Artifact

A specific built binary, package, image, or web bundle, identified by an immutable digest and provenance.

## Release channel

An update audience/feed: Nightly, Canary, Beta, or Stable. Not a Git branch or deployment environment.

## Environment

An execution/data context: Local, CI, Staging, or Production.

## PR risk versus finding severity

Low/Normal/High/Critical classifies a change's scrutiny. S0–S3 classifies a finding's impact. P0–P4 remains roadmap priority.

## Merge candidate

The exact combined source tree to be integrated against a specified current base. Testing an older PR head is not evidence for it.

## Policy gate

A trusted decision over required current evidence, approvals, and finding dispositions. Markdown instructions alone do not enforce it.

## SETUP task

A prioritized engineering-organization/CI task in the roadmap. Separate from product feature milestones and unresolved product choices.
