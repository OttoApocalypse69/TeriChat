# CLAUDE.md — Agent Attribution Policy

This file is read automatically by Claude Code sessions. It binds every
agent working in this repository, including Codex and other coding agents
that respect this file's intent.

## Do not tag yourself

- Never add self-attribution to commits: no `Co-authored-by: Claude`,
  no `Generated with ...`, no bot trailers of any kind.
- Never add self-attribution to pull requests: no bot signatures,
  taglines, or credit footers in titles, bodies, or comments.
- Never @-mention yourself or react to your own activity for visibility.
- Human authorship stays intact: the commit/PR author is the human owner.

The only exception is an explicit, per-case owner request to include
attribution. Silence is not such a request.

## Read first

Before working, read `AGENTS.md` and follow it. Its authorship rule
("Preserve actual human authorship. Do not add AI co-author trailers
unless explicitly requested.") is the standing policy; this file exists
so automated tooling sees it without being told twice.
